# 30/60/90 evolution

## 0-30 days
- inventory AWS/ECS/RDS/S3/IAM architecture
- map CI/CD and migration paths
- baseline SLOs, alerts, incident history, RTO/RPO, backups, and top cloud costs

## 31-60 days
- connect deployment gate to live AWS state
- add OTel traces, structured logs, service dashboards, release markers
- automate backup restore tests and IAM policy checks
- add preview/staging parity checks for risky changes

## 61-90 days
- progressive delivery/canaries with automated rollback
- cost anomaly budgets per service
- continuous DR evidence and restore exercises
- incident scorecards: change-failure rate, MTTR, alert quality, rollback time
- compliance evidence export for SOC 2/SOC 1 control owners
